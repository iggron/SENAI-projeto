TÍTULO DO PROJETO 
CritRview: Plataforma Centralizada de Avaliações, Críticas e Comparação de Preços de Jogos Eletrônicos 

PROBLEMA
Dificuldade dos jogadores em consolidar opiniões dispersas pela internet e tomar decisões de compra seguras e econômicas.

Incidência de ataques de notas injustificadas (review bombing) que mascaram a real qualidade dos títulos.

Falta de visibilidade, alcance e centralização profissional para críticos especializados e criadores independentes no mercado brasileiro (PT-BR).


SOLUÇÃO 
Desenvolvimento de uma plataforma web que unifica, em um único site, as avaliações de usuários casuais e as análises técnicas de críticos verificados. O sistema oferece filtros de busca, acompanhamento do histórico de valores, garantindo a transparência e a confiabilidade na compra com recomendações para sites seguros, melhores ofertas e mecanismos para coibir o review bombing.





TECNOLOGIAS APLICADAS NA SOLUÇÃO
Linguagens de Programação: HTML5, CSS3, JavaScript / TypeScript (Frontend) e PHP (Backend).
Frameworks e Bibliotecas: Bootstrap, Jquery
Banco de Dados: MySQL (Relacional para gestão de usuários, notas e catálogos) e Redis (Para cache de histórico de preços e buscas frequentes).
Ferramentas de Suporte: Git / GitHub (Controle de versão), Figma (Prototipação e Design UI/UX) e VS Code (Ambiente de desenvolvimento).
METODOLOGIAS APLICADAS NA SOLUÇÃO
Scrum e Kanban: Para gestão ágil do projeto, organização do fluxo de trabalho por sprints e distribuição visual das tarefas. (provavelmente o scrum)
Design Thinking: Para concepção da experiência do usuário (UX), mapeamento de personas (Usuário Padrão x Crítico Profissional) e estruturação do layout focado nas dores dos clientes.
Garantia de Qualidade e Code Review: Aplicação de rotinas de teste e revisão por pares para validação técnica antes de cada entrega.
